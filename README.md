## 1. 项目简介
本项目开发了一套集成于 Scout 机器人底盘的自主跟随与导航系统。系统通过融合单目相机（Camera）与激光雷达（LiDAR）的多源传感器数据，实现了在复杂动态环境中的目标锁定、空间追踪、人工势场（APF）避障以及车道线保持功能。

## 2. 核心算法架构

### 2.1 空间感知与融合
- **YOLOv8 语义感知**：采用 YOLOv8n 轻量化模型进行实时人类目标检测，通过输入尺寸优化（320px）确保边缘计算设备的高帧率运行。
- **多模态投影融合**：利用相机内参矩阵，将 3D LiDAR 点云（PointCloud2）投影至 2D 像素坐标系，实现语义框内的精确物理深度获取。

### 2.2 目标数据关联与追踪
- **空间最邻近匹配 (Nearest Neighbor)**：基于 3D 欧氏距离的锁定算法。系统通过计算候选目标与上一帧锁定位置的物理位移，排除环境干扰人员，实现单一人类目标的稳定锁定。

### 2.3 局部路径规划与避障
- **人工势场法 (APF)**：系统将目标人员设定为引力源，将环境中非目标点云设定为斥力源。
- **混合控制律**：当环境斥力较低时，执行基于视觉 PD 的航向跟随；当障碍物入侵影响半径时，系统自动过渡至势场力导向，执行平滑的连续绕行机动。

### 2.4 可行驶区域检测
- **形态学车道线提取**：通过对图像下半部分（ROI）执行自适应二值化与质心提取，计算车道中心引导向量，为系统提供横向牵引约束。
